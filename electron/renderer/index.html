MAR-429 · DASH-18a

This is a packaging proof build, not the DASH app.

The window opening is the point. This build exists to prove that the Windows package installs, launches, and manages the background Agent Runner correctly through its whole lifecycle.

Everything being proved happens outside this window:

  • the runner starts from inside the installed package
  • closing this window leaves running agents running
  • reopening finds the existing runner instead of starting a second one
  • updating the app does not leave an old runner behind
  • uninstalling leaves no runner process

Evidence lives in runner.log and runner.json in the per-user data directory, and in the main process console — not here. The real DASH interface replaces this page in MAR-432 (DASH-20).

One thing here is real: DASH › Try a sample agent in the menu builds a working agent, asks whether to add it, and runs it. It needs nothing installed.
